# EasyExcel 统计分析与 dashboard

0.8.0 起，左侧「统计分析」可直接选数据、生成图表并组合看板。Electron + TypeScript 负责界面；数据读取、组合、统计和绘图均由本机 Python 完成。无需联网、无需写代码，原文件不修改。

0.9.0 起，选区默认通过本机 Microsoft Excel 在后台渲染。**选区操作始终在 EasyExcel 窗口内**，无需切到 Excel。原有图表、图片、字体、边框、数字格式、合并格、行高列宽由 Excel 自己生成画面，透明选区层使用 Excel 返回的真实坐标。

## 从选区到看板

1. 选择一个 Excel 文件，或包含多个工作簿的文件夹。
2. 点击图表类型，阅读「怎样生成」和「如何选数」。
3. 在数据块中选择工作簿和 Sheet。点击「选区」，等当前区域的 Excel 原样画面加载完成，再拖选矩形；点击或拖动行号/列标可选择整行/整列，Shift + 点击可跨页扩展。点击合并格会选择其完整范围。支持跳到第 100 行之后、向右查看更多列，也可直接输入 `A6:K246`、`B:D`、`6:20`。
4. 范围应包含完整表头和所需数据。设置顶部表头层数；没有表头时填 0，多层合并表头可填 2～10。「建议区域」按检测到的列名和合并表头推测，需检查并排表块、标题和合计行。
5. 数据横向排列时选择「按行 · 每列一条记录」，表头层数改为左侧表头列数。
6. 点击「读取数据并检查字段」，展开样例检查真实来源、字段名称、列标/行号、记录数和前 6 条记录。此样例只在本机显示。
7. 选择分类/时间/X 轴、数值字段和汇总方式。填写标题、单位和注解，点击「生成图表预览」。**单位仅作标注，不换算数值**；金额换成万元需先准备相应数值列。
8. 核对图表下方的数据处理说明和描述统计，点击「加入 dashboard」。可继续添加、编辑、上下调整顺序、刷新或删除图表。

常用布局：总金额指标卡 + 部门预算/实际柱形图 + 月度趋势折线图 + 金额分布直方图。每张图表可以来自不同 Sheet、不同区域，甚至同一数据源文件夹中的不同工作簿。

## Excel 原样画面与公式

- 默认以 100% 显示 Excel 生成的画面，可缩放至 50%～200%；选择范围始终使用真实行列坐标。
- 点击单元格，上方 `fx` 栏显示公式原文；普通单元格显示已保存的值。开启「显示公式原文」后，Excel 将公式直接显示在网格中，列宽可能随 Excel 的公式模式变宽。
- 图表和图片保持原来的相对位置；在其上拖选会选中下方单元格，不会移动或修改图表。
- 每页通常为 40 行 × 20 列，自动扩展以容纳跨页合并格；可上下翻页、左右翻列、输入起始行列。超大行高列宽、超过 80 列/200 行的跨页合并区会提示调整范围。
- 源文件只读。程序创建临时副本，后台 Excel 不显示窗口、不运行宏或事件、不更新外部链接、不重算公式。渲染结束关闭本次独立实例，不影响已经打开的 Excel。公式缺少缓存时，原生画面可能显示空白或 0，统计仍将其作为缺失，并显示说明。
- 原样视图需要 Windows 和可正常使用的 Microsoft Excel，支持 `.xlsx` / `.xlsm`。包含外部连接、活动对象、联网公式或旧式宏表时，不自动打开；可使用「基础值视图」。基础值视图不显示样式、原图表或公式原文，不作为原样还原。
- Excel 生成图片时短暂使用剪贴板，完成后恢复；检测到用户新复制的内容时优先保留新内容。

## 怎样选择对应的图

| 组件 | 选什么数据 | 计算方式与注意点 |
| --- | --- | --- |
| 指标卡 | 一个数值字段 | 合计、平均值、中位数、最小/最大值或有效数值计数 |
| 柱形图 | 一个分类，1～6 个数值字段 | 按分类分组后汇总，适合部门、类别、项目对比 |
| 折线图 | 时间/有序字段，1～6 个数值字段 | 相同时间先汇总，再连线；可按日/月/年分组，不补无记录日期 |
| 饼图 | 一个分类，一个非负数值字段 | 仅支持合计或有效值计数；全部分类参与，负数、零总量和分类超限会报错 |
| 直方图 | 一个数值字段 | 全部有效数值划成 3～50 个等宽区间；区间左闭右开，最后一区间含最大值 |
| 散点图 | X、Y 两个数值字段 | 同一条记录提供一对观测；无效配对排除；相关性不是因果关系 |
| 箱线图 | 1～6 个数值字段 | 中位数、四分位数和 1.5 倍四分位距内的观测；异常点只标识、不删除 |
| 相关性热力图 | 2～6 个数值字段 | Pearson 相关系数，每对字段单独排除缺失，至少 3 对有效观测；常量列或不足配对显示空值 |

箱线图采用 [Matplotlib 的四分位距规则](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.boxplot.html)。相关性使用 [pandas 的逐对完整观测计算](https://pandas.pydata.org/pandas-docs/stable/generated/pandas.DataFrame.corr.html)，每对实际使用的数量会列在图表数据中。

## 跨 Sheet 怎样组合

**追加同类记录**适用于多个期间、多个部门的同结构明细。添加 2～4 个数据块后选择追加：字段名必须唯一且一致，可以顺序不同，程序按名字对齐，不按列位置猜测。数据块的表头层数应使最终字段名一致。

**按共同字段关联**适用于预算表、实际表和其他指标表。为每块选择共同字段，例如项目编号。当前支持一对一：每张表中的键必须唯一，重复时拒绝生成，避免金额被重复放大。可选择「交集」或「保留首表」。空键排除，未匹配键数量会显示；保留首表时，缺失指标保持缺失，不补零。

文本编号和数值编号不混用，`"001"` 不会自动匹配数字 `1`；空白文字键会排除。没有共同唯一键时，应先在 Python 工作台整理或汇总，不能依靠两张表恰好有相同行数来配对。

## 数据清理与统计口径

- 默认不包含隐藏行列；可以在对应数据块中开启。隐藏 Sheet 不可选择，需在本机确认后取消隐藏。选区窗口会用浅灰标识隐藏位置，默认不显示其值。
- 默认排除前两个字段**完全等于**「合计」「小计」「总计」「平均」「平均值」的记录；可关闭。只选数值列时没有合计标签可判断，须手动缩小范围。不会按“最后一行”自动删除记录。
- 完全空白的记录排除。合并内容只在表头范围展开，数据区合并值不向下复制，避免重复计入。
- 公式只使用工作簿已保存的结果，不重算、不运行宏、不刷新外部链接。缺少缓存、Excel 错误值会提示并按缺失处理。在 Excel 重算并保存后，可刷新图表。
- 数值文字支持明确的千分位、货币符号和百分号（如 `25%` 为 `0.25`）；日期、布尔值、无法识别的单位文字不当作数字。不会把非数值或缺失值改成零。
- 描述统计包含有效数量、缺失数、非数值数、合计、平均值、中位数、极值、样本标准差（`ddof=1`）及 25%/75% 分位数。统计针对组合后的全部输入数值，图表因分类为空或展示上限排除的部分会另有说明。
- 柱形/折线图可设置排序和最多 60 个显示分类。超过时只显示当前排序的前 N 类并提示；描述统计仍覆盖全部输入。饼图不能截掉部分分类再算占比。
- 散点图超过 5,000 个有效配对时，均匀抽点只用于显示，相关统计仍使用全部有效配对。来源、行数和生成时间会随每张图保存。

## 保存、刷新与导出

看板配置自动保存在当前 EasyExcel 用户目录对应的本机浏览器存储中，只保存数据源路径、选区、字段和图表设置；重新启动后点击「刷新全部图表」重新计算。不会把图表结果作为有效的实时数据自动恢复。

「保存方案」导出 JSON，「导入方案」恢复设置。方案不含脚本，也不自动执行代码；换电脑后需确保路径可用，或编辑图表重新选择数据源。原字段改变时刷新会报错，需编辑并重新检查字段。

「导出离线报告」生成独立目录，包含：

- `dashboard.html`：可离线打开的看板，图表内嵌，不依赖远程脚本或字体。
- `chart_XX.png`：图表图片，指标卡除外。
- `chart_XX_data.csv` 与 `chart_XX_statistics.csv`：图表数据和完整描述统计。
- `dashboard-plan.json`：可再次导入的分析方案。

报告包含**真实统计结果**和数据来源，只在用户指定的本机目录生成；它不属于给 AI 的脱敏资料。需要对外编程参考时，使用单独的「脱敏导出」。导出前会检查数据文件与图表所依据的版本是否一致，原文件已变时先刷新图表。

## 当前范围

每张图最多 4 个数据区域、合计 500,000 个区域单元格，每块最多 256 列/转置后 256 个字段，最远可读取第 100,000 行；每个文件压缩前后均不超过 200 MB。整行整列超过限制时会报错，不静默裁成前 100 行。看板最多 12 张图，每张最多 6 个数值系列。

关联目前仅支持单个共同字段的一对一匹配；复杂多键、模糊匹配、预测模型和自定义计算字段继续使用 Python 工作台。生成任务最多运行 5 分钟，可停止。所有生成物单独保存，不修改源表。

## 开发验证

在项目根目录运行 `python -m pytest tests/test_analysis.py -q`；桌面目录运行 `npm run build` 后，使用 `npm run test:analysis` 测试实际界面。打包版使用 `EXCELROUTER_PACKAGED_EXE` 指定 EXE，再运行 `npm run test:analysis:packaged`。测试产物通过 `EXCELROUTER_TEST_DIR` 指向仓库外目录。

安装 Microsoft Excel 的 Windows 电脑可运行 `npm run test:native-preview` / `npm run test:native-preview:packaged` 验证真实原样选区。Python 测试设置 `EASYEXCEL_TEST_NATIVE=1` 后运行 `pytest tests/test_native_preview.py`，包括其他 Excel 实例保留、原文件不变、原图表像素、合并边界和公式校验。
