EasyExcel 免安装版（Windows 64 位）

使用方法
1. 右键 ZIP 压缩包，选择“全部解压缩”，解压到一个独立文件夹。
2. 打开解压后的文件夹，双击 EasyExcel.exe。
3. 选择 Excel 文件或文件夹，勾选需要处理的 Sheet，再执行拆分或汇总。

多 Sheet 总工作簿（0.4.0）
拆分时打开“同时生成总工作簿”，结果目录内会额外生成“总工作簿/拆分结果总表.xlsx”，原分表保留。
已有分表可在“Excel 汇总”中选择所在文件夹，勾选需要的 Sheet，将“汇总方式”设为“每个表独立一个 Sheet”。每张表独立保留，不要求列结构相同。
单 Sheet 文件使用文件名命名，多 Sheet 文件使用“文件名_原 Sheet 名”；名称过长、非法字符及重名会自动处理。处理全部数据行，保留常见样式、合并区域与行高列宽。普通整理使用公式已保存的计算结果；图片、图表及 Excel 表对象不复制。

表格预览显示原表第 1～100 行（包含标题和表头），保留常见单元格样式与合并区域，可缩放或展开查看。隐藏行列不显示。图片、图表、条件格式和部分特殊数字格式暂不能完整复现。

本包包含运行所需的 Electron 界面、Python 引擎及依赖，无需另行安装 Python、Node.js 或 Microsoft Excel。表格处理在本机完成，可以离线使用。

请完整保留解压后的所有文件和子目录，包括 resources、locales 及 DLL 文件。不要只复制 EasyExcel.exe，也不要在压缩包内直接双击运行。复制到另一台 Windows 64 位电脑时，请复制整个文件夹或原始 ZIP 包。

最近任务记录保存在当前 Windows 用户的应用数据目录，不随程序文件夹迁移。处理结果保存在界面显示的输出位置。程序关闭后可直接删除解压的程序文件夹；这不会删除已另存的 Excel 结果。

本版提供 Sheet 选择、预览、按字段拆分、普通汇总和离线 Python 工作台。Excel 文件的读取和处理仍由内置 Python 引擎负责。

离线 Python 工作台
1. 选择表格和需要处理的 Sheet，打开左侧“Python 工作台”。
2. 点击“给 AI 的说明”，导出编程说明，填写你的需求后转移到有网电脑。
3. 在有网电脑上让 AI 按说明生成 UTF-8 编码的 .py 脚本，拷回离线电脑。
4. 点击“导入 .py”，检查代码，点击“运行代码”（Ctrl+Enter）。
5. 查看结果、图表和日志；报错时可复制日志带回联网电脑请 AI 修改。

内置 pandas、numpy、matplotlib、openpyxl、xlrd，以及 numpy-financial、PyXIRR、SciPy、statsmodels、QuantLib、XlsxWriter、Seaborn、Babel 和 Python 内置 decimal；环境版本、用途和导入方式可在运行设置中查看，AI 编程说明也会列出这些库。程序不需要联网安装依赖。让 AI 只使用说明中列出的库；要用其他第三方库，需要在有网开发机上重新打包，不能只拷贝脚本。

df 是第一张勾选表的完整数据，tables 包含全部勾选表；前 100 行只是原表预览限制。代码默认读取表头以下的数据，隐藏列不载入，隐藏行及合计行保留，公式使用已保存的缓存值。数据类型和空值按 pandas 默认规则识别。代码以当前用户的本机权限执行，请检查脚本的输出路径；每次运行使用独立结果文件夹，自动保存脚本、环境版本和日志，停止后的文件可能不完整。数据分析导出默认保留数据值；需要保留原表样式时使用“Excel 拆分 / Excel 汇总”。

脚本库
运行过的脚本会自动收录。打开“我的脚本库”，可以改名称、分类、写使用说明、收藏、搜索，再点“载入编辑器”或“载入并运行”。相同代码累计运行次数，修改代码后保留另一份记录。加载使用当前勾选的 Sheet；当前未收录的编辑内容会暂存为草稿。

移入回收站的脚本可恢复。脚本库保存在当前 Windows 用户目录，升级程序会保留；换电脑请在旧电脑点击“备份”，拷贝 JSON 备份到新电脑后点“导入备份”。备份包含脚本及其说明，不包含输入表格；代码里自己写入的业务常量会随脚本保存。重复导入会合并相同代码，不重复累计次数。

财务功能
新增现金流、现值终值、贷款本金利息、不规则日期 XIRR / XNPV、统计回归预测、债券利率估值、金额格式化和 Excel 财务报表能力。内置“贷款试算”和“金额核对”代码示例。金额计算用 Decimal(str(value)) 并明确舍入规则；行情、汇率、利率等输入仍需由本地数据或参数提供。

品牌更新
0.3.1 起软件更名为 EasyExcel，并使用新的照片头像图标。原 ExcelRouter 版本的脚本库、最近任务与编辑草稿继续从当前用户的原保存位置读取；旧版脚本库备份也可正常导入。
