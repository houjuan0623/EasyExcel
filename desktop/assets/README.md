# EasyExcel 应用图标

最终图标直接裁切用户提供的原照片，没有重绘人物。原图尺寸为 898 × 1488，裁切区域为 `(8, 70, 890, 890)`，依次表示左上角 x、y、宽、高。

- `app.png`：512 × 512，用于界面品牌标识与非 Windows 窗口。
- `app.ico`：16、20、24、32、40、48、64、128、256 像素的 32 位图标，用于 Windows 可执行文件、窗口和快捷方式。

用 Windows 自带的图形库完成裁切、缩放和格式转换，重新生成命令：

```powershell
.\desktop\scripts\make-app-icon.ps1 -Source '原照片.jpg'
```

曾使用内置 imagegen 工具预览方形构图，提示要求为“保留原人物与色调，仅裁切面部为方形，无文字或边框”。生成预览改变了照片细节，因此没有放入软件；实际打包只使用上述直接来自原照片的文件。
